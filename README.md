# Alcohol or Gasoline

Aplicativo Android para auxiliar na escolha entre Álcool e Gasolina,
calculando o melhor custo-benefício com base nos preços atuais.

## Video da Execução
- [Demonstração]()

| Requisito | Status |
| :--- | :---: |
| Salvar e restaurar o estado do Switch | ✅ |
| CRUD de valores de combustível | ✅ |
| Exibição de uma lista de valores de combustível/postos | ✅ |
| Acesso à localização do usuário e exibição do mapa | ✅ |
| Suporte a Internacionalização | ✅ |

## Tecnologias

- **Linguagem:** [Kotlin](https://kotlinlang.org/)
- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Persistência:** SharedPreferences
- **Localização:** Fused Location Provider

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/AlcoholOrGasBasic.git
   ```
2. Abra o projeto no **Android Studio**.
3. Sincronize o Gradle.
4. Execute em um dispositivo físico ou emulador.
